# PROJECT.md

## 프로젝트 개요

여러 PDF로 흩어진 강의자료를 과목·주차별로 정리하고, 페이지 단위 원문 검색부터 원문 확인, 메모와 학습 기록까지 하나의 흐름으로 연결하는 로컬 웹 기반 학습 플랫폼이다.

배경 및 문제 정의: 대학 수업에서는 과목별·주차별로 다수의 PDF 강의자료가 제공되며, 학기가 진행될수록 필요한 개념이 어느 자료의 몇 페이지에 있었는지 다시 찾기 어려워진다. 또한 강의자료를 확인한 뒤 작성하는 메모, 할 일, 공부시간 등의 학습 기록은 별도의 도구에 분산되는 경우가 많다.

대상 사용자: 여러 과목에서 PDf 형태의 강의자료를 활용하여 공부하는 대학생을 주요 사용자로 한다.

## 목표

최종 목표: 최종적으로는 사용자가 과목 및 주차별로 PDF 강의자료를 등록하고, 등록된 자료의 텍스트를 페이지 단위로 검색하여 검색 결과에서 해당 원문 페이지를 열람하고 메모를 작성할 수 있는 로컬 웹 애플리케이션을 완성한다. MVP를 우선 완성한 뒤 이미지 PDF의 OCR, 할 일 및 공부시간 기록, 강의자료 기반 AI 학습 기능 등을 단계적으로 추가한다.

### P0 — 필수 MVP

- 과목·주차 생성 및 PDF 등록·목록·삭제
- 텍스트 PDF 페이지 단위 텍스트 추출·검색
- 이미지 PDF OCR 및 처리 상태·재시도
- 검색 결과에서 해당 PDF 페이지 이동
- PDF 페이지별 메모 CRUD

### P1 — 핵심 흐름 확장

- 과목별 할 일
- 과목별 공부시간
- 자료 근거 기반 요약·퀴즈·질문 (OpenAI-compatible API)

### P2 — 부가 학습 기능

- 타이머
- 뽀모도로 타이머

## 개발 환경 및 기술 스택

| 구분 | 사용 기술 (버전) | 선택 이유 |
| :---- | :---- | :---- |
| 언어 | Python(3.14), TypeScript | PDF/OCR 처리와 웹 UI 구현에 적합  |
| 프레임워크 | FastAPI, React + Vite | FastAPI: REST API 구현이 간결하고 OpenAPI 자동 문서화 React + Vite: PDF Viewer·검색·메모 등 동적 UI 관리 |
| 주요 라이브러리 | PDF.js, pypdf/pdfplumber | [ ] |
| 데이터베이스 | SQLite + FTSS, SQLAlchemy | 별도 DB 서버 없이 로컬 저장 및 전문 검색, 데이터 모델/CRUD 관리 |
| OCR | Tesseract | 이미지 PDF 속 텍스트 인식 |
| 빌드·테스트 도구 | Pytest + Vitest, Github Actions | Backend/Frontend 단위 테스트, PR마다 자동 테스트 |
| 개발 환경 | VS Code, Docker + Docker Compose | Windows와 MacOS을 사용하는 팀원이 모두 있어, 개발 환경을 Docker로 맞추기 위함 |
